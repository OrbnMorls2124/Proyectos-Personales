# Proyecto Final - Programación 2

Este es el proyecto final para la clase de Programación 2. Es una aplicación web sencilla con HTML, CSS y JavaScript.

## Archivos del proyecto
- `index.html`: Página principal.
- `checkout.html`: Proceso de pago.
- `CSS/`: Estilos del sitio.
- `JS/`: Lógica en JavaScript.
